# Security

Artha is a private family app. The data lives in a private Google Sheet reached only through an Apps Script
backend that accepts Google sign-in from two allowlisted accounts. This repository holds only the front end:
no keys or passcodes are stored here. The backend address is in the code by design: it only answers allowlisted Google accounts.

Please report anything that looks like a security problem privately through GitHub's "Report a vulnerability"
(Security tab), not in a public issue.
